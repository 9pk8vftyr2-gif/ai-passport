# Zumi Pocket：设计与验收

首页使用 Talk / Play / Garden 三个编号入口、简短说明和深绿选中行，不再显示角色。
Energy Link 选关页中央显示当前关卡的初始 4×4 线路缩略图，复用游戏线路绘制与完整能源名称，不再显示角色。
UP / DOWN 切换关卡及预览，OK 开始对应棋盘。唤醒卡和 Talk/Garden 占位页的 Zumi 保持不变。


## 交互边界

第一阶段是到货前离线原型。设备使用 Montserrat 英文字符，浏览器说明用中文，不声称已验证中文字库。仅需 UP / DOWN / OK 三键。上下在按下时生效，首页到边停止，选关和可旋转线路循环切换。OK 在释放时确认；500 毫秒长按回首页并消费释放事件；忽略 CLICK / DOUBLE，避免重复动作。电源按钮独立。

游戏关卡/步数信息上移至（22,47），四行棋盘从 y=72 开始；游戏格子为 48×44 像素，初始选关缩略格为 48×34 像素。六关解法均经过第四行。

仅保留 **Energy Link**，6 个重新编排的 4×4 关卡。沿用网站北/东/南/西接头互相对接、从能源连接全部房屋的规则；允许闲置线路。能源、房屋和标记为固定的线索不可旋转。没有倒计时或步数上限。完成后保留棋盘，OK 直接进入下一关棋盘，无关卡间准备页，第六关后回第一关。准备页可自由选关。

只读参考网站版本 `a0504f97fb74a94ea864361f539e5832a16b268f` 的 `game/energy-link/engine.mjs`、`levels.mjs`；未复制 5×5 关卡、Hexapipes 生成关卡。口袋关卡与 C 实现独立编写，不包含网站撤销、持久化功能；音效复用合成参数，也不修改网站。

所有页面（含游戏）无操作 60 秒后背光从 70% 降至 0%，并停止应用重绘。按键恢复 70% 亮度，随机选取八张已审核宣传卡之一，相邻不重复，唤醒按键和欢迎期间按键均消费至释放。欢迎页共 3,000 毫秒：240 毫秒淡入，保持至 2,640 毫秒，360 毫秒淡出；随后原游戏或首页 240 毫秒淡入：游戏中唤醒恢复原关卡、线路、步数、光标和通关状态；其他页面唤醒回首页。游戏数据在欢迎期间保留于 RAM，恢复不会重播音效或自动进入下一关。每个表情页面角落均显示 `zco.eco`。仅唤醒欢迎页在角色上方显示 “Zumi Pocket”，其他屏幕页面不显示该品牌标题。逐对象透明度不依赖全屏合成缓冲。每次操作重新计时；欢迎页 3 秒不计入随后页面的闲置时间。熄屏后的迟到释放／长按事件不会唤醒，唤醒画面在恢复背光前更新。CPU、按键轮询及已初始化音频资源继续运行，属于熄屏待机，不是深度休眠；真实省电量待测。电量来自原 BSP，失败显示 `--`；Talk / Garden 返回未连接，不执行 I/O。

## 离线唤醒宣传卡

八张卡分别复用本地 Zumi: Office Vibes 的挥手、迈步、点赞、闭眼放松、交流、观察、鼓掌和感谢表情／动作。背景与文案采用已审核 V3 设计，Zumi Pocket 和 zco.eco 已包含在图内；电量在淡入淡出期间保持可见。素材来自用户本地表情包，不声称为已验证微信发布版本。

宣传卡替代 Tiny Actions 清单；Garden 恢复未连接服务占位，OK 返回首页。Talk 同样未连接，不记录完成进度或写入存储。开机仍进首页，宣传卡仅在熄屏后按键唤醒时出现。相邻卡不重复，不保证短期内等频或整轮不重复。

已审核合成图与原表情哈希保存在 `assets/images/zumi-pocket/wake-cards/source/`。用 `node tools/build_zumi_wake_cards.cjs` 转换为 8 张 240×320 小端 RGB565，共 1,228,800 字节只读 Flash。浏览器 PNG 使用相同 RGB565 量化颜色。固件采用图像透明度直接使用原 BSP 局部绘制缓冲，避免对象透明度中间层及整帧 PNG/JPEG 解码；实际帧率仍需真机验证。

检查官方硬件文档与 BSP 时未发现运动传感器接口。用户已选择等硬件确认后再做运动检测与一小时站立提醒，本版不启用运动检测、每小时计时或未按键计时替代。

## 完整标签与共用音效

能源及房屋格复用 Eco Pop 的黄色太阳、浅蓝风机、橙色建筑图标；底部保留完整 `Solar power > House` / `Wind power > House` 说明。第 3、5 关为风能，能源类型不改变连接规则。
网站版本 `a0504f97fb74a94ea864361f539e5832a16b268f` 的原图、裁切坐标和哈希记录于 `assets/images/zumi-pocket/energy-icons/manifest.json`。按用户要求将建筑/需求图标用作 House；两张原 PNG 存于 `source/`，不代表新增第三方再分发授权。
`node tools/build_energy_link_icons.cjs` 生成六张 32×32 RGB565 亮/暗图标，共 12,2104 字节 Flash；缩略图按 28×28 显示。固件仅链接小图，浏览器 PNG 使用相同量化颜色。

六关 4×4 棋盘分别有 2、2、3、4、4、5 个房屋。`tests/zumi_difficulty.c` 通过独立位掩码连通判定和穷举方向搜索，证明最少顺时针旋转次数为 **8、13、16、18、20、25**；不包含选格按键次数。这是客观操作成本，不是真人完成时间测试。主机门禁要求最少旋转次数逐关递增，无倒计时或失败惩罚。

音效参数来自相同网站版本的 `game.mjs`：正弦波、12 毫秒指数起音，增益从 0.0001 升到 0.045，再衰减到 0.0001，尾音 20 毫秒。旋转为 330 Hz / 70 毫秒；新增房屋通电为 659.25 Hz / 70 毫秒。通关立即播放通电音，620 毫秒后播放 523.25 / 659.25 / 783.99 Hz 三音，时长 180 / 180 / 250 毫秒，偏移 0 / 100 / 200 毫秒。参数存于 `assets/music/zumi-link-tones.json`，用 `python3 tools/build_zumi_sounds.py` 生成，不使用外部音频媒体或服务。

三份 16 kHz、16 位单声道 PCM 共占 Flash 20,800 字节。浏览器和设备共用事件判定与 PCM；浏览器首次按键解锁声音，页面隐藏或失焦停止。新声音替换旧声音以限制快按积压，退出游戏取消待播通关音。

设备使用不持有 UI 指针的常驻音频任务、单槽覆盖队列和 4,0104 字节栈，512 字节 PCM 分块缓冲位于该栈。仅该任务调用原 BSP 音频接口，首次播放时初始化；阻塞写入不在按键回调或界面任务内，音频失败不影响游玩。每块检查取消，已经送入 DMA 的声音可能继续约 90 毫秒。初始硬件音量设为 60%，并不代表物理响度已和网站一致。首次使用后保留音频硬件资源；电流与显示/音频并发需实测。不读取麦克风。

## 架构与资源

- 共享 C 状态机 104 字节，无动态分配；恢复运行时单次更新时间最多 100 毫秒。固件以 esp_random() 初始化非安全随机数，测试固定种子便于复现。
- 绘制列表最多 64 项，每份 6,404 字节，固件两份共 12,808 字节。复用 LVGL 对象，仅更新变化项。
- 单一应用任务、非阻塞有限按键队列；LVGL 操作持有 BSP 锁，电池读取在锁外。
- 三张 78×92 RGB565 图片共占 Flash 43,056 字节；没有全屏图片解码缓冲。BSP DMA 局部缓冲 19,200 字节，LVGL 内存池仍为 24 KB。实际峰值内存、对象分配和碎片需真机验证。
- 原 BSP 与 8 MB 分区表不变，无 PSRAM。新增 Montserrat 10 小号网址字体，保留 14/20。原硬件测试界面仅留源码参考，不链接。
- 无 NVS 保存、联网、录音或休眠。浏览器用相同 C 逻辑和视图编译 WASM，通过 Canvas 绘制，字体与时序不等同物理屏幕。

## 硬件到货验收清单 — NOT RUN

本阶段没有刷写、重置、擦除或打开设备。未来刷机须另行明确授权，并指定设备与镜像。

1. 核对板型、版本、8 MB Flash、数据线和构建镜像校验值；刷写前确认 NVS 保留方式，合并镜像可能重置存储。
2. 检查启动直达 Zumi 首页、240×320 竖屏、圆角、颜色和文字；确认首页/选关页无角色，六关缩略图与实际棋盘对应；在保留角色的页面检查帽子标识；对照已审核原图验收基础表情与八张宣传卡。
3. 测试三键快按、选关/线路循环、跳过固定格；长 OK 及释放不得误开 Talk 或多转线路。
4. 完成六关：接头互通才导电、全部房屋才胜利、分支与固定线索正确、完成棋盘保留、下一关/重玩/退出正常。
5. 在各页面（含游戏）等待 60 秒，确认背光完全关闭；超时前操作应重新计时。分别用三键唤醒；检查不同宣传卡、Zumi Pocket 与网址、3 秒停留和平滑切换回原游戏或首页；验证反复唤醒后关卡、线路、步数、光标及通关状态保留，重新短按 OK 可继续游戏或进入下一关；持续按住唤醒键越过欢迎页也不能误触。
6. 离线反复唤醒，检查八张不同卡片、相邻不重复；无行动完成清单、一小时提醒或运动检测。断网时游戏与卡片均可用，Talk/Garden 服务未连接。
7. 连续 30 分钟、100 次切页，记录最小空闲堆、最大块、LVGL 峰值、看门狗、输入延迟和帧率。
8. 对照网站试听旋转、通电和通关音，检查响度、失真、退出取消、快按、codec 不可用与音画并发。检查真实电量与读数失败，测量亮屏/熄屏/游戏电流与温度；续航和真机动画顺滑度尚未验证。
9. 授权后断电重启，确认会话重置、应用不写入或擦除无关存储。
10. 逐项记录板型、镜像哈希和结果证据后才可判定 Device Tests PASS/FAIL；浏览器截图不能替代真机验收。
