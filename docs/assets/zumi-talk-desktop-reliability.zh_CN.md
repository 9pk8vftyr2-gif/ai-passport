# 电脑端 Talk 自动启动、播放与说话动画

2026-10-19。没有刷写设备。官方语音仍通过电脑适配器接入；实体固件保留本地 PCM 适配器。

> 历史验收记录：下文的定时嘴型与分段音源播放已被
> [声音驱动嘴型与连续播放](zumi-talk-audio-envelope.zh_CN.md)取代。

## 已安装服务

`tools/talk_autostart.py` 安装三个用户级 LaunchAgent：本地预览 8876、本地模拟 8881、
官方语音中继 8882。设置登录启动、退出后自动拉起、十秒重启节流。登录只启动监听服务，
不录音、不调用 AI 推理；进程不再依赖 Codex 任务的生命周期。需要用户已登录；电脑
睡眠、网络不可用、账号过期仍可能中断 Talk。

运行副本放在 `~/Library/Application Support/Zumi Pocket/desktop-runtime`。
原因是 macOS 拒绝后台 Python 访问 Documents 中的项目虚拟环境。只安装选定文件，
无需开放整个 Documents 的访问权限。凭据留在上一级应用支持目录，位于 HTTP 根目录
之外，也不写入 plist。修改源码或资源后，需要刷新运行副本。现有 Python、libopus
路径须保持可用。没有接入收费服务或安装新的系统软件包。

```sh
# 在项目目录中，使用已有 Talk 环境和本机 libopus 路径。
ZUMI_OPUS_LIBRARY=/absolute/path/to/libopus.dylib build/talk-venv/bin/python tools/talk_autostart.py install
build/talk-venv/bin/python tools/talk_autostart.py status
build/talk-venv/bin/python tools/talk_autostart.py remove
```

`remove` 只停止并移除这三个启动任务，保留运行副本和账号配置。服务日志丢弃，不累积
可能带有语音内容的日志。状态命令只报告进程状态和退出码。

## 播放和界面

前台 Talk 断线后按 2–15 秒间隔自动重连；返回焦点时立即尝试。隐藏页面、熄屏及其他
模块不会重连。重连不开麦，不重发旧录音。小智实际不可用时仍会显示 Offline。

官方电脑模式协商最多 36 帧缓冲（720 ms，浮点采样本身 46,080 字节，另有浏览器对象
开销）。起播预留 300 ms；实际断流后计数并重新预留 200 ms。播放额度保证队列有上限。
旧客户端、本地模拟及设备预算仍为 12 帧。这会增加一点起播等待，用于容忍网络和界面
短时停顿，不能消除任意长延迟。打断会立即停止排队音频。

MIC OFF 居中放到 78×92 角色正下方。回复时每 140 ms 在原版张嘴与闭嘴帧之间切换，
结束或打断后恢复原表情。只有嘴部范围内 125 个像素不同，身体、眼睛、帽子与身份
不变。这是随回复状态运行的嘴型动画，不是逐音素口型同步。第四帧 RGB565 增加
14,352 字节 Flash，不使用视频或全屏动画缓冲。

官方人设已要求网址按“W、W、W，点，Z、C、O，点，E、C、O”逐字母读出，保存后
完整回读一致，Memory 仍关闭。这只是发音规则，没有发布网站或更改域名。

## 证据与边界

见[机器可读测试记录](talk-v1/desktop-reliability.json)。合成媒体测试不代表真人识别率
或主观听感验收。实际退出登录、重新登录及整机重启尚未验证。实体屏幕、麦克风、
扬声器、运行时 Heap、续航测试均为 **NOT RUN**。

| 检查 | 结果 |
| --- | --- |
| Build | PASS，ESP-IDF 5.5.3；应用 2,756,880 字节，factory 分区剩余 5,566,192 字节 |
| Host Tests | PASS，包含嘴型复位与协商播放额度边界 |
| Browser Demo | PASS，本地游戏/唤醒回归、麦克风生命周期、两种嘴型与自动重连 |
| 受控播放 | 注入 250 ms 传输停顿及 180 ms 界面卡顿：240/240 帧、断流 0、最大队列 36 |
| 编译期间的官方测试 | 三轮完整回答及打断恢复通过，但有 5 次断流，平滑度未通过 |
| 编译结束后的官方测试 | 三轮完整回答及打断恢复通过，断流 0、最大队列 25、全部麦克风音轨关闭 |
| 服务重启 | 主动终止中继后自动拉起；官方 TLS/握手通过 |
| Device Tests | NOT RUN |

归档及匹配 ELF 的哈希见测试记录。两轮官方结果都保留；编译与断流同时发生，不能据此
断言全部断流均由编译造成。没有修改原网站或上游 main。

合成语音询问网址时，原始转录正确，官方回答为“网址是 W W W，点，Z C O，点，E C O。”，
285 个音频块完整返回。实际发音听感仍需用户试听确认。
