REVIEW CONTROLS

试试断网和打断

以下是预览测试工具，不是设备菜单。

01 / Idle

准备好了，麦克风关闭。

02 / Listening

红色录音指示与计时，最长 15 秒。

03 / Processing

麦克风关闭，显示识别文字。

04 / Speaking

回答文字与播放提示，可随时打断。

05 / Offline

停止采集，重新连接后重新开始。

06 / Error

说明错误，重试不重发旧录音。
